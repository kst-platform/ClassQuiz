# КСТ.Квиз

Своя live-квиз-платформа (сервер + клиент, вход по PIN/QR с телефона) для
ГБПОУ «Колледж современных технологий имени Героя Советского Союза
М.Ф. Панова» (КСТ).

Это форк открытого проекта [ClassQuiz](https://github.com/mawoka-myblock/classquiz)
(MPL-2.0) — код, лицензия и авторство апстрима сохранены в `LICENSE` и
`LICENSES/`. Поверх апстрима сделаны: фирменный дизайн колледжа вместо
бренда ClassQuiz, регистрация преподавателей с одобрением администратором,
управление учётками из админ-панели, группы студентов и импорт вопросов
из формата GIFT.

**Ход работы и статус фаз — в `KST_TODO.md`.** План изначальной разработки
описан в скиле `~/.claude/skills/svoy-kahut/` (выбор движка, критерии,
чек-лист деплоя на стенд).

## Разработка

Та же настройка, что у апстрима — Pipenv для бэкенда (FastAPI), pnpm для
фронтенда (SvelteKit), Postgres + Redis + Meilisearch через
`docker-compose.dev.yml`. Подробности когда-то были на classquiz.de/docs —
после форка эти страницы предстоит переписать под себя (см. `KST_TODO.md`,
Фаза 1).
